# CLOSET CHECK

> 「なんとなく買う」をなくし、納得して洋服を購入する。

古着屋やアパレルショップで、洋服の状態とサイズ感を 2〜5 分でチェックできるスマートフォン向け Web アプリです。
Google スプレッドシートをデータベース、Google Apps Script（GAS）をバックエンドにしています。外部ライブラリは使っていません。

## できること

| 機能 | 内容 |
|---|---|
| 古着の状態チェック | 生地・シミ・ダメージ・ニオイの 20 項目を「問題なし／気になる／未確認」でチェック |
| 試着・フィット感チェック | 肩・丈・パンツ・動作の 20 項目。関係ないカテゴリーは「対象外」に |
| NG例の見本 | チェック中に NG 例の画像を確認 |
| 購入判定 | 問題の**重大さ**を優先して「買い／要検討／見送り」を参考表示（最終判断はユーザー） |
| 商品情報の保存 | 商品名・ブランド・価格・メモと一緒にスプレッドシートへ保存 |
| 購入履歴 | 保存した商品の一覧と、項目ごとのチェック結果 |
| マイクローゼット | Google ドライブの手持ちの服の写真をカテゴリー別に表示。試着中に見比べられる |
| 配色パターン | スプレッドシートで作った色の組み合わせを、色の帯とカードで表示 |

スマートフォン向けに、途中経過の自動保存（再読み込みしても復元）や、Android の戻るボタンへの対応も行っています。

## ファイル構成

```
closet-check/
├── src/                  … Apps Script に貼り付けるファイル
│   ├── Code.gs           … サーバー処理（設定・初期化・判定・保存・履歴・写真・配色）
│   ├── Index.html        … 画面の骨組み
│   ├── Style.html        … デザイン（CSS）
│   └── JavaScript.html   … 画面の動き
├── docs/
│   ├── SETUP.md          … 導入・デプロイ・運用の手順  ← まずはこちら
│   ├── TESTING.md        … 動作確認チェックリスト
│   ├── TROUBLESHOOTING.md… エラー対処ガイド
│   └── DESIGN.md         … 設計書（システム構成・シート設計・判定ルール）
└── tests/                … Code.gs の自動テスト（node closet-check/tests/run.js）
```

## はじめかた

1. [docs/SETUP.md](docs/SETUP.md) の手順でスプレッドシートを作り、`src/` の 4 ファイルを Apps Script に貼り付ける
2. `setupSpreadsheet` を実行してシートを作成
3. Web アプリとしてデプロイし、スマートフォンで開く
4. [docs/TESTING.md](docs/TESTING.md) で動作を確認

困ったときは [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) を見てください。

## スプレッドシートの構成

| シート | 内容 | 編集してよいか |
|---|---|---|
| Checklist | チェック項目のマスター | ○（項目の追加・変更・無効化） |
| PurchaseHistory | 保存したチェック結果 | △（行の削除は可。checked_items_json 列は編集しない） |
| Settings | アプリの設定 | ○（B 列の値） |
| ColorPatterns | 配色パターン | ○（追加・変更・無効化） |

どのシートも **1 行目（見出し）は変更しないでください**。
