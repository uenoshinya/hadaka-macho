## 自動テスト（開発者向け）

`Code.gs` の主要な処理は、Google のサービスの「まね」を使ってパソコン上で自動テストできます。
Code.gs を修正したら、貼り付ける前に実行してください（[Node.js](https://nodejs.org/) が必要です）。

```bash
node closet-check/tests/run.js
```

| テスト | 内容 |
|---|---|
| 初期化 | シート作成・初期データ・再実行で既存データが消えない・ヘッダー不一致の検出 |
| 購入判定ルール | 重大 1 つで見送り、注意 1 つで要検討・3 つで見送り、軽微 3 つで要検討、未確認・進捗不足、対象外、悪い方を総合判定、しきい値の変更 |
| 保存 | 正常保存・二重保存防止・数式インジェクション対策・全項目の入力チェック・ロック取得失敗 |
| 購入履歴 | 新しい順・件数上限・空行・壊れた JSON |
| NG例の見本画像 | URL / ID の読み取り・画像以外・大きすぎる・見つからない |
| マイクローゼット・配色パターン | 許可フォルダ外の写真を読まない・縮小画像・拡大画像の取得順・色コードの検証・割合 |

開発時には、このほかにブラウザ（Playwright）でスマートフォン画面を操作するテストも実施し、
上の 1〜8 の多くの項目（Android の戻るボタンは疑似的に）を確認済みです。
