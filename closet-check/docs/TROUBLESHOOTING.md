# CLOSET CHECK エラー対処ガイド

困ったときは、まず **「表示されたメッセージ」** を下の表で探してください。
アプリのエラーメッセージは、原因と直し方が分かるように書いてあります。

---

## 1. まず試すこと（どのエラーでも共通）

1. **アプリを開き直す**（ページの再読み込み）。途中のチェックは自動で復元されます
2. **電波を確認する**。店内で電波が弱いときは、入口付近など電波の良い場所で再試行
3. **Google アカウントを確認する**。スマートフォンのブラウザで、デプロイしたのと同じアカウントでログインしているか
4. **最新のコードがデプロイされているか**。「デプロイを管理」→「新バージョン」で公開し直す

---

## 2. 導入・デプロイ時のエラー

| 症状・メッセージ | 原因 | 対処 |
|---|---|---|
| 「スクリプト関数 doGet が見つかりません」 | Code.gs が保存されていない／貼り付けが途中で切れている | Code.gs を貼り直して保存し、「新バージョン」でデプロイし直す |
| 「ファイル Style が見つかりません」（Index・JavaScript も同様） | HTML ファイルの名前が違う | ファイル名を `Index`・`Style`・`JavaScript` に（大文字・小文字も一致）。`.html.html` になっていないか確認 |
| 画面に `<?!= include('Style'); ?>` という文字が出る | Index の中身が正しくない | Index を貼り直す |
| 画面が真っ白／デザインが崩れている | Style か JavaScript の貼り付けが途中で切れている | 各ファイルの**最後の行**（`</style>`・`</script>`）を確認して貼り直す |
| 「このアプリは Google で確認されていません」 | 自作スクリプトでは必ず表示される | 「詳細」→「（安全ではないページ）に移動」→「許可」 |
| 「アクセス権が必要です」（スマートフォン） | スマートフォンで別のアカウントにログインしている | デプロイしたのと同じ Google アカウントでログインする |
| コードを直したのにアプリが変わらない | デプロイを更新していない | 「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」 |
| URL が変わってしまった | 「新しいデプロイ」を使った | 以後は「デプロイを管理」で更新する。新しい URL をホーム画面に追加し直す |

## 3. アプリ使用中のエラー

| 症状・メッセージ | 原因 | 対処 |
|---|---|---|
| 「読み込みに失敗しました」 | 通信エラー、または初期化前 | 「再読み込み」を押す。続く場合は `setupSpreadsheet` を実行 |
| 「シート『○○』の 1 行目（見出し）が想定と異なります」 | シートの 1 行目を編集した | 1 行目を元に戻す（下の「4. シートの見出し」参照）。右側に列を足すのは問題ありません |
| 「チェック項目がありません」 | Checklist が空、または全項目の active が外れている | `setupSpreadsheet` を実行するか、active にチェックを入れる |
| 追加したチェック項目が表示されない | active にチェックがない／target_type・severity の入力ミス／item_id の重複 | active にチェック。target_type は `vintage`・`fitting`・`both`、severity は `normal`・`warning`・`critical` のいずれか |
| 「判定できませんでした」 | 通信エラー | 「もう一度判定する」を押す |
| 「保存できませんでした」 | 通信エラー | 入力内容は残っているので、そのまま「この内容で保存」を押す（二重に保存されることはありません） |
| 「保存が混み合っています」 | 同時に別の保存が実行中 | 数秒待ってから再度保存 |
| 「入力内容を確認してください：…」 | 入力値の問題 | メッセージの内容に従って修正 |
| 「この記録は保存済みです」 | 同じチェックを 2 回保存しようとした | 問題ありません（1 件だけ保存されています） |
| 「この記録は見つかりませんでした」（履歴の詳細） | スプレッドシートから行を削除した | 履歴を開き直す |
| 履歴の詳細に「チェックの詳細を読み込めませんでした」 | PurchaseHistory の checked_items_json 列を手で編集した | 商品情報は表示されます。チェック詳細は元に戻せないため、この列は編集しないでください |

## 4. 画像・写真のエラー

| 症状・メッセージ | 原因 | 対処 |
|---|---|---|
| 「NG例の見本を見る」ボタンが出ない | `GUIDE_IMAGE_FILE_ID` が空 | Settings に画像の共有 URL を設定し、アプリを開き直す |
| 「見本画像が見つかりません」 | URL の間違い／ファイルがゴミ箱にある | 共有リンクを取り直して貼り直す |
| 「見本画像が大きすぎます」 | 5MB を超えている | 画像を縮小（長辺 2000px 程度）してアップロードし直す |
| 「手持ちの服フォルダの URL を設定してください」 | `WARDROBE_FOLDER_ID` が空 | Settings にフォルダの URL を設定する |
| 「手持ちの服フォルダが見つかりません」 | URL の間違い | フォルダを開いた状態のアドレスバーの URL を貼り直す |
| 「写真が見つかりませんでした」 | フォルダにサブフォルダや写真がない | カテゴリーごとのサブフォルダを作り、写真を入れる |
| 一覧で写真の代わりにファイル名が出る | ドライブの縮小画像がまだ作られていない（アップロード直後） | 数分待ってからアプリを開き直す |
| 「この写真は表示できませんでした」 | ブラウザで表示できない形式 | JPEG か PNG に変換してアップロードし直す |
| 写真を追加したのに表示されない | アプリが写真の一覧を覚えている | アプリを開き直す |
| 「手持ちの服を見る」ボタンが出ない | `WARDROBE_FOLDER_ID` が空、または `WARDROBE_LINK_ITEM_IDS` の ID が違う | Settings を確認する |

## 5. スマートフォン特有の症状

| 症状 | 原因 | 対処 |
|---|---|---|
| 再読み込みするとチェックが消える | プライベートブラウズ（シークレットモード）で開いている | 通常のブラウズで開く（途中経過を保存できないため） |
| Android の戻るボタンでアプリが閉じる | ホーム画面で 2 回押した | 仕様です（ホーム画面では 2 回目で閉じます） |
| 入力欄をタップすると画面が拡大される | 古い iOS の仕様 | ピンチで戻す（入力欄は 16px 以上にしてあり、通常は起きません） |

---

## 6. エラーの詳しい内容を調べる

1. Apps Script エディタの左メニュー **「実行数」**（時計のアイコン）を開く
2. 失敗した実行（赤いアイコン）をクリックすると、エラーの詳しい内容が表示されます
3. 分からないときは、その画面のスクリーンショットと、アプリに表示されたメッセージを控えて相談してください

## 7. シートの見出し（1 行目）

1 行目を誤って編集してしまったときは、次のとおりに戻してください（左の列から順に）。

| シート | 1 行目 |
|---|---|
| Checklist | item_id, category, item_name, target_type, severity, active, display_order |
| PurchaseHistory | record_id, created_at, product_name, brand, category, condition_type, price, condition_result, fitting_result, judgment, memo, checked_items_json |
| Settings | key, value, description |
| ColorPatterns | pattern_id, group, pattern_name, color1_name, color1_hex, color2_name, color2_hex, color3_name, color3_hex, color4_name, color4_hex, ratio, memo, active, display_order |

## 8. やり直したいとき

- **チェック項目を最初の状態に戻す**：Checklist シートの 2 行目以降を削除して `setupSpreadsheet` を実行
- **配色パターンを最初の状態に戻す**：ColorPatterns シートの 2 行目以降を削除して `setupSpreadsheet` を実行
- **シートを消してしまった**：`setupSpreadsheet` を実行すると作り直されます（データは戻らないため、定期的なバックアップをおすすめします）

## 9. Google の利用上限

無料の Google アカウントでも個人利用なら上限に達することはまずありませんが、
短時間に大量の写真を開くと、一時的に「サービスの呼び出し回数が多すぎます」と表示されることがあります。
その場合は時間をおいて再試行してください（上限は翌日にリセットされます）。
