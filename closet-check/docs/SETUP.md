# CLOSET CHECK 導入・運用手順書

プログラミングの経験がなくても、この手順どおりに進めれば使い始められます。
所要時間の目安は 20〜30 分です。作業はパソコンの Chrome で行うのがおすすめです。

---

## 1. 用意するもの

- Google アカウント（Gmail のアカウントで OK）
- パソコン（コードの貼り付けに使います。完成後はスマートフォンだけで使えます）
- 必要に応じて
  - NG例の見本画像（1 枚）
  - 手持ちの服の写真

---

## 2. スプレッドシートを作る

1. [Google ドライブ](https://drive.google.com/) で「新規」→「Google スプレッドシート」を選ぶ
2. 左上の「無題のスプレッドシート」を「CLOSET CHECK」に変更する

> このスプレッドシートがアプリのデータベースになります。削除しないでください。

---

## 3. コードを配置する

### 3-1. Apps Script を開く

スプレッドシートのメニューで **「拡張機能」→「Apps Script」** を選びます。新しいタブでエディタが開きます。
左上の「無題のプロジェクト」も「CLOSET CHECK」に変えておくと分かりやすいです。

### 3-2. 4 つのファイルを用意する

| Apps Script でのファイル名 | 作り方 | 中身 |
|---|---|---|
| `コード.gs`（または `Code.gs`） | 最初からあるファイルを使う | `src/Code.gs` |
| `Index` | 「＋」→「HTML」→ 名前を `Index` | `src/Index.html` |
| `Style` | 「＋」→「HTML」→ 名前を `Style` | `src/Style.html` |
| `JavaScript` | 「＋」→「HTML」→ 名前を `JavaScript` | `src/JavaScript.html` |

**貼り付けのしかた（1 ファイルずつ）**

1. コードをコピーする（GitHub のファイル画面右上の「Copy raw file」ボタンを使うと全文を一度にコピーできます）
2. Apps Script のファイルを開き、中身を全選択（Ctrl+A / ⌘A）して削除
3. 貼り付け（Ctrl+V / ⌘V）→ 保存（Ctrl+S / ⌘S）
4. エディタの一番下までスクロールし、**最後の行**が下の表と同じか確認する（途中で切れていないかの確認）

| ファイル | 最後の行 |
|---|---|
| コード.gs | `}` |
| Index | `</html>` |
| Style | `</style>` |
| JavaScript | `</script>` |

**よくある間違い**

- HTML ファイルの名前に `.html` を付けない（自動で付きます。`Index.html.html` になると動きません）
- 大文字・小文字を正確に（`index` や `style` は不可）
- 新しく作った HTML ファイルに最初から入っている `<!DOCTYPE html>…` は全部消してから貼り付ける

---

## 4. スプレッドシートを初期化する（最初に 1 回）

1. エディタ上部の関数名の欄で **`setupSpreadsheet`** を選び、「▷ 実行」を押す
2. 権限の確認が表示されたら
   1. 「権限を確認」→ 自分のアカウントを選ぶ
   2. 「このアプリは Google で確認されていません」と出たら **「詳細」→「CLOSET CHECK（安全ではないページ）に移動」**
      （自分で作ったスクリプトなので問題ありません）
   3. 「許可」を押す
3. 実行ログに「初期化が完了しました」と出れば成功です

スプレッドシートに次の 4 つのシートができます。

| シート | 内容 |
|---|---|
| Checklist | チェック項目（40 項目） |
| PurchaseHistory | 保存したチェック結果（最初は空） |
| Settings | アプリの設定 |
| ColorPatterns | 配色パターン（10 件） |

> `setupSpreadsheet` は何度実行しても、入っているデータは消えません。
> 次にスプレッドシートを開いたときから、メニューの「CLOSET CHECK → 初期化」からも実行できます。

**権限について**：このアプリは次の権限を使います。
- スプレッドシートの読み書き（チェック結果の保存）
- Google ドライブの読み取り（NG例の見本画像・手持ちの服の写真の表示）
- 外部サービスへの接続（手持ちの服の写真を、ほどよい大きさに縮小して取得するため）

---

## 5. 設定する（Settings シート）

B 列（value）を書き換えると、アプリの動きを変えられます。変更はアプリを開き直すと反映されます（再デプロイは不要）。

| key | 初期値 | 説明 |
|---|---|---|
| APP_NAME | CLOSET CHECK | 画面上部のアプリ名 |
| CATEGORY_OPTIONS | シャツ,Tシャツ,ニット,ジャケット,コート,パンツ,その他 | 商品カテゴリーの選択肢（カンマ区切り） |
| WARNING_SKIP_THRESHOLD | 3 | 注意項目の「気になる」がこの数以上で「見送り」 |
| NORMAL_CONSIDER_THRESHOLD | 3 | 軽微な項目の「気になる」がこの数以上で「要検討」 |
| MIN_PROGRESS_FOR_BUY | 0.8 | 「買い」に必要な確認の割合（0.8 = 80%） |
| PRICE_MAX | 10000000 | 入力できる価格の上限（円） |
| HISTORY_LIMIT | 100 | 購入履歴に表示する件数 |
| GUIDE_IMAGE_FILE_ID | （空） | NG例の見本画像の共有 URL |
| WARDROBE_FOLDER_ID | （空） | 手持ちの服フォルダの URL |
| WARDROBE_LINK_ITEM_IDS | F20 | 「手持ちの服を見る」ボタンを付けるチェック項目の ID |

### 5-1. NG例の見本画像（任意）

1. 画像を Google ドライブにアップロードする（共有設定は「自分のみ」のままで OK）
2. ファイルを右クリック →「共有」→「リンクをコピー」
3. Settings の `GUIDE_IMAGE_FILE_ID` の B 列に貼り付ける

画像は「左半分＝古着の状態」「右半分＝試着」の 1 枚を想定しています。

### 5-2. マイクローゼット（任意）

1. ドライブに「CLOSET CHECK 手持ちの服」のようなフォルダを作る
2. その中に **カテゴリーごとのサブフォルダ**（トップス・パンツ・アウター・シューズ など）を作り、写真を入れる
3. フォルダを開いた状態でアドレスバーの URL をコピーし、`WARDROBE_FOLDER_ID` の B 列に貼り付ける

サブフォルダ名がそのままアプリのタブ名になります。写真は新しい順に表示されます。

## 6. Web アプリとして公開する（デプロイ）

1. エディタ右上の **「デプロイ」→「新しいデプロイ」**
2. 「種類の選択」の歯車アイコン → **「ウェブアプリ」**
3. 次のとおり設定して「デプロイ」
   - 説明：`v1` など自由
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

### スマートフォンで開く

1. URL を自分宛てにメールや LINE で送り、スマートフォンで開く
2. スマートフォンのブラウザでも、**同じ Google アカウントでログイン**しておく
3. ホーム画面に追加しておくと、店頭ですぐ開けます
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：「︙」→「ホーム画面に追加」

---

## 7. コードを更新したとき

コードを貼り替えて保存しただけでは、公開中のアプリには反映されません。

1. 「デプロイ」→ **「デプロイを管理」**
2. 右上の鉛筆アイコン（編集）
3. 「バージョン」で **「新バージョン」** を選び「デプロイ」

> 「新しいデプロイ」を使うと URL が変わってしまうので注意してください。
> Code.gs を変更したときは、念のため `setupSpreadsheet` も 1 回実行してください（新しいシートや設定が追加されることがあります）。

## 8. 日々の運用

### チェック項目を追加・変更する（Checklist シート）

| 列 | 書き方 |
|---|---|
| item_id | 重ならない ID（例：`C21`、`F21`）。**一度決めたら変えない** |
| category | 見出し（同じ文字のものが 1 つのカテゴリーにまとまる） |
| item_name | 項目の文（「〜ないか」の形がおすすめ） |
| target_type | `vintage`（古着の状態）／`fitting`（試着）／`both`（両方） |
| severity | `critical`（1 つでも気になれば見送り）／`warning`（注意）／`normal`（軽微） |
| active | **チェックを入れると表示**。項目を消したいときは行を削除せずチェックを外す |
| display_order | 表示順（小さい順）。間に入れたいときは 15 のような中間の数字に |

### 配色パターンを追加する（ColorPatterns シート）

- 1 行が 1 パターン。色は最大 4 色（`color1_name`・`color1_hex` 〜 `color4_…`）
- 色コードは `#4A3015` のように入力すると、セルがその色に塗られます
  （色コードは「カラーピッカー」で検索すると調べられます）
- `ratio` に `5:3:2` のように書くと、帯の幅がその割合になります（空なら均等）
- 表示しないパターンは `active` のチェックを外す

### 手持ちの服の写真を追加する

スマートフォンのドライブアプリから、該当するサブフォルダに写真をアップロードするだけです。

### データのバックアップ

スプレッドシートの「ファイル」→「コピーを作成」で丸ごと保存できます。月に 1 回程度がおすすめです。
